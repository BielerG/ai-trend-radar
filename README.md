### 🔥 Top 3 Highlights

1. **Microsoft MAI-Image 2.5 launched at Microsoft Build (June 2).** First dual text-to-image + image-to-image model in one API. Ranks #3 on LM Arena behind gpt-image-2 and Nano Banana 2. Live in PowerPoint and on Microsoft Foundry — meaning teams on the Microsoft stack now have an on-platform option without a separate third-party API contract. [Source](https://en.ain.ua/2026/06/03/six-updates-from-microsoft-build-2026/)

2. **TwelveLabs launches Rodeo — natural-language video editing copilot (June 1).** Find, assemble, and cut raw footage through plain-text prompts. Powered by Marengo 3.0 + Pegasus 1.5. Signals where video assembly is heading: manual shot-sequencing time will compress significantly as these tools mature. [Source](https://www.prweb.com/releases/twelvelabs-bring-its-video-understanding-technology-directly-to-creators-302786228.html)

3. **Canva design now live inside Perplexity Computer (June 5).** Research and design happen in a single session — a trend spotted in a search becomes a formatted creative asset without any export/import round-trip. Closes the research-to-asset gap for rapid-response creative workflows. [Source](https://www.analyticsinsight.net/press-release/from-ai-research-to-ready-to-use-creative-canva-comes-to-perplexity-computer)
